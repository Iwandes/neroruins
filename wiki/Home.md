# NeroRuins Wiki

Player- and contributor-facing documentation for **NeroRuins**, part of the
Neroland ecosystem. Built on **Neroland Core**.

> **Status:** in development. Data shards and the player archive are available for testing; shards
> currently have no survival source. Finished ruin families and their gameplay are not yet available.

Add one page per block, item, machine, or system as it is built, and link it here. Keep this page as
the index.

## Error reporting

NeroRuins sends anonymous, mod-specific error reports to its Sentry project in the EU by
default. Set `telemetryEnabled=false` in `config/neroruins.properties` and restart to opt out.
See the [privacy disclosure](../PRIVACY.md) for details.
